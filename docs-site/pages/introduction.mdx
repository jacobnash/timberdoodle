Timberdoodle is an ontology-agnostic building data platform: API-first,
load-time-pluggable (Brick/Haystack/DBO), headless by design. Time-series
readings live in Postgres/TimescaleDB — so Grafana, or anything else that
speaks SQL, reads them natively, no plugin required. Entity and
relationship data lives in Oxigraph as RDF, queryable over SPARQL.

It feeds from FBF (BACnet/Modbus → MQTT, a sibling project) over the same
wire envelope both `mqtt_listener.py` and `POST /ingest` consume.
